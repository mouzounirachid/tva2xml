# TVA2XML - Convertisseur Excel vers XML

Version prête pour Railway / Render

## Déploiement Railway
1. Upload ce dossier sur GitHub
2. Railway → New Project → GitHub Repository
3. Sélectionne ce repo
4. Railway lance automatiquement `npm install` et `node app.js`

## Fichiers inclus
- app.js : application avec conversion en arrière-plan (anti-504)
- package.json : dépendances
- modele_tva.xlsx : modèle Excel
